# Deepak Kumar — Personal Portfolio

A responsive one-page portfolio built with plain HTML, CSS and JavaScript.

## Files
- index.html — page structure
- style.css — responsive design
- script.js — navigation and animations

## GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save and wait for GitHub Pages to publish the site.

Before publishing, replace `your.email@example.com` in `index.html` with your real email address.
